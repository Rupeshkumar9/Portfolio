# 🚀 Rupesh Kumar — Portfolio

My personal developer portfolio built with vanilla HTML, CSS, and JavaScript. Featuring an interactive starfield animation, HUD-style project cards, and a skills marquee.

## ✨ Features

- **Starfield Animation** — Canvas-based warp-speed star trails with mouse-reactive speed control
- **HUD Project Cards** — Glassmorphism cards with blue glow hover effects and pulsing borders
- **Skills Marquee** — Auto-scrolling tech stack icons (Languages → Frameworks → Tools)
- **Typewriter Effect** — Cycling through developer roles in the hero section
- **Scroll Reveal** — Elements fade in as you scroll using Intersection Observer
- **Timeline** — Visual journey from BCA student to full-stack developer
- **Animated Stats** — Count-up counters triggered on scroll
- **Fully Responsive** — Mobile, tablet, and desktop layouts
- **Dark Theme** — Ultra-dark `#050505` background with blue + purple accents
